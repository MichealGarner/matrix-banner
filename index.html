Matrix-themed login banner — for Debian Linux

A three-layer login experience inspired by Metasploit and the Matrix. Animated typewriter greetings, live system stats, colourised ANSI art, and a legal warning that means business.

Download & install View on GitHub See the demo

features

>_
Animated typewriter
Random Matrix-style greetings personalised with $USER, printed character by character at login.
##
Live system stats
Kernel, IP, uptime, load, memory, disk usage, and pending apt updates — all pulled fresh at login time.
!!
Legal warning
Pre-auth SSH banner and colourised in-shell warning. Computer Misuse Act 1990 compliant. They have been warned.
/*
Debian-native
Uses /etc/update-motd.d/ PAM hooks, /etc/profile.d/, and sshd_config — no daemons, no cron.
>>
Multi-host deploy
Single installer script. Deploy to a fleet with a simple rsync loop or Ansible. One command per host.
~~
Safe & reversible
Backs up every file it touches with a timestamp. Validates sshd_config before reloading. Includes uninstaller.

how it works

01
SSH pre-authentication banner
Shown to everyone before they authenticate — including uninvited guests. Plain text, no ANSI (client support not guaranteed at this stage). Controlled by the Banner directive in sshd_config.
/etc/ssh/banner.txt
02
Dynamic MOTD
PAM assembles the MOTD at login by running all executable scripts in /etc/update-motd.d/. Outputs the warning box and live system stats — no static file, always current.
/etc/update-motd.d/10-matrix-motd
03
Animated shell banner
Runs for all users in interactive login shells via /etc/profile.d/. Typewriter animation, random personalised greeting, ASCII art, colourised stats panel. Plays after the MOTD.
/etc/profile.d/00-matrix-banner.sh

install

single host — debian
wget https://github.com/MichealGarner/matrix-banner/releases/latest/download/matrix-banner.tar.gz
tar -xzf matrix-banner.tar.gz
sudo bash matrix-banner/install.sh
multiple hosts — rsync loop
HOSTS="server1 server2 server3"
for HOST in $HOSTS; do
rsync -av matrix-banner/ root@${HOST}:/tmp/matrix-banner/
ssh root@${HOST} "bash /tmp/matrix-banner/install.sh"
done
uninstall
sudo bash matrix-banner/uninstall.sh
# Restores backups, removes all files, reloads sshd
